## Deliberate exclusions, not hidden completion claims

This goal is a six-iteration local trial. Full coding-agent performance gains, public
release, native hooks, Claude adoption, CI, new-card creation, hosted Langfuse,
automatic promotion and full accessibility certification were not promised as
delivered results. No finding permits relaxing freshness, adding execution authority,
claiming isolated-snapshot checks, or reporting unknown costs as zero.

The initial measurements did not continuously instrument all implementation/browser
effort. The goal explicitly permits missing measurements to remain unknown; the
assessment does so instead of inventing retrospective timing. The iteration-4
process deviation and retained failures are evidence about harness use, not removed
from the record to make the trial appear cleaner.
