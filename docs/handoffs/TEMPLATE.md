# Handoff template

Status: template only. Populate from observed repository state.

- Task ID and brief: [reference].
- Contract revision, if registered: [revision or not registered].
- Repository/worktree and base/current state: [identity].
- Installed Checkpoint artifact, if any: [version/hash or disabled].
- Candidate source revision: [identity].
- Scope attempted and files changed: [facts].
- Commands actually executed: [command, working directory, result, timestamp/reference].
- Evidence freshness and execution mode: [facts or unavailable].
- Unresolved criteria and blockers: [specific missing evidence].
- Next suggested action: [scoped step].
- Recovery needs: [pending processes, separate candidate state, migration/rollback considerations].

Do not write only “tests passed.” Name the commands and evidence. Never include secrets or raw provider payloads by default.
